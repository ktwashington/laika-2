# Laika - A Mindful Student Productivity Planner!

This project is a continuation of an idea I had in high school --> https://github.com/ktwashington/Laika
This time around, with more experience on my shoulders and the help of AI, I was able to bring my vision mostly to life. This project is still a work in progress, hence many changes must be made ‼️

This project is the second in a series of websites/applications made with JS + React + Typescript, all of which I'm currently learning.

## Official Tech Stack
- Frontend: React, TypeScript, Vite, CSS
- Backend and data: Supabase
- Version Control: Git and GitHub

## Key Features
Laika is designed to help students build sustainable study habits without sacrificing their well-being.

<img width="1440" height="743" alt="image" src="https://github.com/user-attachments/assets/43d7744c-0f41-466a-9fc8-d0a97cc34026" />

Current and planned functionality includes:
- Study Planning: Organize study sessions and academic tasks in one place.
- Focus Tools: Create a dedicated environment for focused work.
- Task Management: Break academic responsibilities into more manageable steps.
- Session Management: Save and revisit study plans and sessions.
- Mindful Productivity: Encourage students to balance focused work with breaks and rest.

Features are actively being developed, so availability and functionality may change as the project evolves.

## What role did AI play in the creation of Laika?

I believe in being transparent about my development process, including how I use AI as a programming tool.

As a solo developer, I used AI as a collaborative assistant, particularly when implementing backend functionality and working through unfamiliar concepts. However, AI-generated code was not treated as automatically correct. I reviewed its output, examined how it fit into the existing application, and made decisions about whether and how to integrate it.

For me, AI is a tool for learning, problem-solving, and accelerating development-not a replacement for understanding the code I'm responsible for maintaining.

As Laika continues to grow, I aim to strengthen my understanding of its architecture, security, data handling, and overall reliability.

## Why is this project important to me?
As a student myself, I've seen first hand how difficult it can be to balance school work, social outings, and extracurriculars. Rather than students cramming in their homework, I believe it's important to have a proper study schedule that includes brain-breaks to help reduce stress/strain. Hence, why I created Laika! The mindfulness of students is often disregared, even by themselves, simply for the sake of being productive. My application poses the question... why not have both?

## Challenges & What I'm Learning
Laika is an opportunity for me to move beyond smaller projects and apply my growing software development skills to a more complete application.
Throughout the development, I've been working on:
- Building reusable components and organizing a React application.
- Using TypeScript to define data structures and improve code clarity.
- Implementing routing and connecting different pages into a cohesive experience.
- Managing application state and persisted study-session data.
- Debugging integration issues and understanding how frontend components interact with backend services.

Rather than limiting myself to technologies I already know, I'm using Laika to learn through implementation, experimentation, and iteration.
